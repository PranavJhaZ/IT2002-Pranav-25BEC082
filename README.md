# IT2002 - Data Structures and Algorithms

Coursework and laboratory implementations for IT2002.

## Directory Structure

* **Assignment1_Python_Basics/**
  * `Assignment1_Python_Basics.ipynb`: Python basics covering operators, collections, control flow, functions, file handling, and exceptions.

* **Algorithm_Analysis_Labs/**
  * `lab1.py`: Benchmarking algorithmic growth rates ($O(1)$ through $O(2^n)$).
  * `lab2.py`: Comparison of prefix average implementations ($O(n^2)$ vs $O(n)$).

* **Assignments_Extended/**
  * **PartA_Recursion/**: Recursive algorithms (factorial, sum, power, in-place reversal, sorted check, Fibonacci tree, Tower of Hanoi, tail-recursion).
  * **PartB_Arrays/**: Shallow copy versus deep copy behavior.
  * **PartC_Stacks_Queues/**: List-based Stack, Circular Queue, and Circular Deque.
  * **PartD_LinkedLists/**: Singly Linked List operations and Favorites List ADT.
